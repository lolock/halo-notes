# Halo Notes 视觉规范

方向：人文科技杂志，以瑞士网格组织版面。让技术长文具有沉静、清晰的阅读节奏。

- 色彩：暖白纸色 `#f4f0e7`、墨色 `#262820`、朱砂强调 `#9c422c`。深色采用暖炭灰 `#20221f`，避免纯黑与荧光色。
- 字体：衬线用于刊头、文章标题与长文；无衬线用于导航和辅助信息；等宽仅用于编号与日期。优先系统字体回退，不以外部字体加载成功为前提。
- 网格：首页宽屏三栏，最新文章横跨全宽，以图文两栏呈现；平板两栏，手机一栏。筛选结果恢复平等的文章网格，首项不再放大。
- 层级：中英文标题分行，英文为次级字号；保留原题全文。正文按既定 magazine-v1 小节组织，宽屏双语并列、手机依次阅读，不逐行对齐。
- 封面：原图保持原色；无图时使用统一的暖色文字封面，以细边、编号和主题文字组成。保留图片加载失败回退。
- 细节：直角、细线、充足留白；去除霓虹渐变、胶囊堆叠与技术版本标签。首页序号表达当前列表位置，不代表编辑评分。
- 主题：未保存偏好时使用暖白日间主题；用户主动选择深色后跨页面保持。

样式入口为 `assets/editorial.css`，由首页、reader.html 和兼容入口 article.html 共享。原有 bilingual.css 保持双语布局职责。
