# Halo Notes 视觉规范

方向：人文科技杂志，以瑞士网格组织版面。让技术长文具有沉静、清晰的阅读节奏。

- 色彩：暖白纸色 `#f4f0e7`、墨色 `#262820`、朱砂强调 `#9c422c`。深色采用暖炭灰 `#20221f`，避免纯黑与荧光色。
- 字体：衬线用于刊头、文章标题与长文；无衬线用于导航和辅助信息；等宽仅用于代码。优先系统字体回退，不以外部字体加载成功为前提。
- 网格：首页宽屏三栏，最新文章横跨全宽，以图文两栏呈现；平板两栏，手机一栏。筛选结果恢复平等的文章网格，首项不再放大。
- 层级：中英文标题分行，英文为次级字号；保留原题全文。正文按既定 magazine-v1 小节组织，宽屏双语并列、手机依次阅读，不逐行对齐。
- 封面：原图保持原色；无图时使用统一的暖色文字封面，以细边和主题文字组成。保留图片加载失败回退。
- 细节：直角、细线、充足留白；去除霓虹渐变、胶囊堆叠与技术版本标签。首页只保留刊名、检索、折叠分类和文章列表；删除宣传标语、装饰编号及重复标签。
- 主题：未保存偏好时使用暖白日间主题；用户主动选择深色后跨页面保持。

样式入口为 `assets/editorial.css`，由首页、reader.html 和兼容入口 article.html 共享。reader.css 负责阅读结构，bilingual.css 保持双语布局职责。所有按钮使用相同字体、44px 最小点击高度、细边框及交互状态；深色模式使用明确文字和 aria-pressed，不使用表情图标。

阅读页的来源元信息保存在可展开的“来源信息”中；不修改文章 Markdown。常驻工具栏仅保留文章目录与深色模式，移除原始 Markdown 技术入口。表格、代码块、引用与正文共用相同墨色、细线与强调色。
