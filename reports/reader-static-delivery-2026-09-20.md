# 阅读器布局与静态文章交付验收

本次包含两个独立工作包：阅读器布局/样式职责，以及 Markdown 构建为完整静态文章。保留工作区原有双语分组改动，未改写文章正文。下文记录本地实现与验收结果；上线状态以对应提交的 GitHub Pages 部署运行和线上验收收据为准。

## 已完成

- `editorial.css` 负责变量和共享控件，`reader.css` 负责阅读器布局与公共正文，`bilingual.css` 负责双语结构与语言差异。
- 页面改用 document 滚动，标题定位、进度、高亮与历史导航使用同一坐标体系。
- 双语以正文容器 864px 为分栏条件；目录仅在完整正文和侧栏都能容纳时进入侧边，不压缩正文。
- 普通文章纸面最大 816px，双语最大 1088px。以当前字体和留白测得单语侧栏约 1107px、双语侧栏约 1390px、双语分栏约 981px；这些视口数值是测量结果，不是 JS 中另一套断点。
- 共享渲染模块供构建与旧加载器复用，静态文章仅加载 reader.js 增强交互。
- 构建生成 173 篇文章：171 篇索引文章和 2 篇历史保留文章，包含标题、描述、canonical、Open Graph 和原生目录。
- 首页指向生成文章，旧 reader/article 参数链接保留 hash 后跳转；源码目录没有构建映射时保留 Markdown 预览。
- CI 安装锁定构建依赖、验证并构建公开目录；线上 verify 改为逐字节检查生成 HTML 和阅读器资源。
- 修复无 JavaScript 窄屏目录展开后遮挡目标标题：无脚本顶部目录随页面滚动，增强后保留 sticky 和自动折叠，宽屏侧栏继续 sticky。
- 生成索引时归一化 7 张首页封面的旧站点前缀，保证根目录预览与自定义部署前缀可用，保留外部 URL 的原语义。

## 验证结果

- Python 回归：16 项通过，包括静态 HTML、CSS 和旧链接映射陈旧时必须拒绝 verified。
- 内容严格校验：171 条索引、173 个 Markdown，0 错误、0 警告。
- 既有双语结构及分组回归通过。
- 最终静态交付回归：656 项断言、173 篇文章通过；覆盖生成 HTML、元数据、路径与清洗、资源、输出保护、重复构建确定性及根路径/自定义前缀。
- 源码浏览器回归：171 篇文字/链接/图片/代码保留，95 篇具有双语结构；Jev 的 390/850/1440、深浅主题、真实图片、目录、深链接、打印通过。
- 独立导航浏览器回归：根路径及 `/halo-notes/` 前缀通过。覆盖恶意目标拒绝、无效路径、加载重试、监听不重复、浏览器前进后退、延迟图片定位及用户开始阅读后停止自动校正。
- CSS 浏览器连续扫描：普通/双语各约 140 个宽度，范围 300–1600px；正文宽度不随视口增加而缩小，无页面横向溢出，paper 不承担主滚动。另验收了无目录布局和 240px 高度视口。
- 静态站点浏览器回归：16 个代表及边界宽度、无解析脚本请求、元数据、旧入口、无 JavaScript 正文/目录、主题、图片、打印和首页链接。
- 全量静态审计：173 篇正文与共享渲染的 textContent 一致；2725 个本地资源/链接路径存在；101 个 OG 图片路径存在。
- 最终构建后的本地 HTTP 发布验收通过：临时重建结果与预览服务器实际返回的文章 HTML、Markdown、资源、兼容映射和构建清单逐字节一致。验收收据只写临时目录，没有把本次检查记作线上发布。
- 资源缓存版本、JS 语法及 `git diff --check` 均通过。

浏览器截图、尺寸记录与打印 PDF 位于 `/tmp/halo-reader-delivery/`。本地操作及维护入口见 [阅读器架构](../docs/reader-architecture.md)。

## 验证边界

- 旧参数入口的兼容跳转需要 JavaScript；无脚本阅读使用新静态文章 URL。首页的内容索引仍通过 JavaScript 加载。
- Reader Mode 和分享平台的实际识别/缓存效果尚未在各目标平台验证；已经核对初始 HTML 的正文与元数据，不承诺搜索排名。
- `the-anatomy-of-effective-commerce-agents-双语.md` 原文已有 8 个指向不存在 `#ca-p1`–`#ca-p4` 的中英文文内链接。新旧渲染均存在该内容问题，本次没有改写文章；阅读器生成的目录锚点正常。
