HTML 已嵌入正文、脚本和原图，可下载后用浏览器直接打开。约17MB是为了离线审阅，不代表生产页面应有的体积。外部原文链接仍需联网。文件名后添加 `?lead=3` 可审阅摄影作为主文章的布局，添加 `?gray=1` 可看灰度版本。

## 具体变化

同一篇主文章，390×844 CSS 像素视口下：

| 指标 | 现站基线 | 提案 |
| --- | ---: | ---: |
| 第一篇标题起点 | 约605px | 153px |
| 首篇图片区域高度 | 约233px | 140px |
| 图片展示 | 3:2容器中留白 | 按原图约2.5:1完整展示 |

提案首屏可以看到第一篇完整标题、摘要、配图，以及下一篇标题。坐标从网页视口顶部计算，不包含手机状态栏与浏览器工具栏。

手机首页主标题24px、列表标题20px；阅读页字号保持不变。390px宽度的当前样例中，主标题从三行收为两行，高度约70px；第一条后续标题约60px。

刊头在默认手机字号下为56px，搜索与菜单保留44px点击区域；搜索按需出现，主题设置进入菜单。首页统一显示中文标题和中文摘要，中英双语文章在分类、日期旁用“双语”文字标识，阅读页保留完整双语。文章标题先于大图，无图文章用文字排版，不添加占位封面。截图保持原比例；摄影主图16:9仅是经逐图审阅的候选，列表摄影缩略图4:3。当前摄影样例保留主要人物，不能据此直接批量裁切全库。

## 验证与边界

- Chromium 在390px与1440px宽度下无页面横向溢出。
- 搜索、空结果恢复、菜单、主题、目录及离线图片加载检查通过；浏览器控制台未记录错误。
- 首页按计算字号模拟200%文字放大，无页面横向溢出。此项允许内容自然变高，不要求维持默认首屏位置。
- 五篇样例的标题、正文、图片与链接逐一对照通过。标题排版中分离中英标题，不改写文章内容。
- 普通文字、辅助文字、强调色相对纸面背景的对比度：浅色13.13 / 5.13 / 5.87，深色12.91 / 7.97 / 7.77，均高于4.5:1；这不等于完整无障碍合规认证。
- 本次使用五篇现有文章覆盖长标题、双语、截图、摄影及无图情形，未对全站168篇进行新版回归；未做真实用户测试或iPhone实机验收。

验证记录：[布局与交互](measurements.json)、[文章完整性](content-check.json)、[配色对比度](contrast-check.json)。

审阅重点是首屏是否容易判断文章内容、列表能否快速扫描，以及长篇双语是否适合连续阅读。生产实现与发布不在本轮交付内。
