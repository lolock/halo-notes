> EN: Starting today, the memory you use in chat is the same as in Claude Cowork. Now, wherever you work with Claude, it starts from what it already knows about you. You can see everything Claude remembers, topic by topic, and edit or delete any of it. Claude does not store subjects considered sensitive, like health or beliefs, to memory by default, but if those are the topics you're tired of re-explaining, you can turn them on in Memory settings.
> ZH: 从今天开始，您在聊天中使用的记忆与在 Claude Cowork 中使用的记忆相同。现在，无论您在哪里与 Claude 合作，它都会从它已经了解的您开始。您可以按主题查看Claude记住的所有内容，并编辑或删除其中任何内容。默认情况下，Claude不会将健康或信仰等敏感主题存储到记忆中，但如果您厌倦了重新解释这些主题，则可以在“记忆”设置中将其打开。

## Claude Cowork 和聊天的一段回忆 / One memory across Claude Cowork and chat

> EN: Cowork now has memory, and it’s the same one you use in chat, leading to less re-explaining and more picking up where you left off. When Cowork runs a task in the cloud, what Claude remembers from your chats is there, and vice versa. The context you've built up across months of conversations—for instance, your Q3 priorities and the status of your projects—is there the moment you hand Cowork a task, and what comes up in Cowork carries back to chat.
> ZH: Cowork 现在具有记忆功能，并且与您在聊天中使用的记忆功能相同，从而减少重新解释的次数，并更多地从上次中断的地方继续。当 Cowork 在云端运行任务时，Claude从你们的聊天中记住的内容就在那里，反之亦然。您在数月的对话中建立的背景信息（例如，您的第三季度优先事项和项目的状态）在您向 Cowork 交付任务的那一刻就存在，并且 Cowork 中出现的内容会带回到聊天中。

> EN: Ask Cowork to draft an update for your manager, and it already knows who that is and how she likes updates written. Brainstorm the agenda in chat for a conference you’re organizing; when Cowork builds the budget and logistics doc, it knows the headcount, the city, and the speakers. Explain once in chat how your team defines its metrics, and every quarterly business review deck Cowork builds after that uses them, with no rebriefing.
> ZH: 让 Cowork 为你的经理起草一份更新，它已经知道那人是谁以及她喜欢如何编写更新。在聊天中集体讨论您正在组织的会议的议程；当 Cowork 构建预算和后勤文档时，它知道员工人数、城市和演讲者。在聊天中解释一次您的团队如何定义其指标，以及 Cowork 之后构建的每个季度业务审查平台都使用它们，无需重新汇报。

## 聊天时记忆会更新 / Memory updates as you chat

> EN: Claude now adds topics to memory as you chat, instead of summarizing conversations after they end. Mention that your project deadline moved to September, and your next conversation already knows without you having to say "remember this." You can pause memory or reset it at any time.
> ZH: Claude现在可以在聊天时将主题添加到记忆中，而不是在对话结束后进行总结。提到你的项目截止日期已移至九月，你的下一次谈话就已经知道了，而不必说“记住这一点”。您可以随时暂停记忆或重置记忆。

## 查看并编辑您保存的记忆 / See and edit your saved memories

> EN: Everything Claude remembers is in a list of files under Topics in Memory settings, where you can read, edit, or delete each one. The files are short, and a fix pays off everywhere: correct your company's old name in one file and every conversation from then on gets it right.
> ZH: Claude记住的所有内容都在“记忆主题”设置下的文件列表中，您可以在其中读取、编辑或删除每个文件。这些文件很短，修复后到处都有回报：在一个文件中更正公司的旧名称，从此以后的每次对话都会正确无误。

## 决定是否希望Claude记住敏感话题 / Decide if you want Claude to remember sensitive topics

> EN: By default, Claude does not store topics related to personal or sensitive subject matter, like your health, race, ethnicity, religious beliefs, politics, gender identity, and other similar areas.
> ZH: 默认情况下，Claude 不会存储与个人或敏感主题相关的主题，例如您的健康、种族、民族、宗教信仰、政治、性别认同和其他类似领域。

> EN: But what some consider sensitive, others may consider useful for Claude to remember. If you choose to turn on “include sensitive topics in memory,” Claude will remember things like your gluten allergy when suggesting recipes for weekly meal prep.
> ZH: 但有些人认为敏感的内容，其他人可能认为对Claude记住有用。如果您选择打开“在记忆中包含敏感主题”，Claude在建议每周准备膳食的食谱时会记住您的麸质过敏等事情。

> EN: With the setting turned on, each time Claude saves something on one of these topics to memory, you’ll see a notice. Claude saves sensitive topics going forward. Anything from before you turned it on isn't saved retroactively. You can turn off this setting at any time.
> ZH: 启用该设置后，每次Claude将这些主题之一的内容保存到记忆中时，您都会看到一条通知。Claude保留了接下来的敏感话题。打开它之前的任何内容都不会追溯保存。您可以随时关闭此设置。

> EN: To protect your safety and privacy, there are some topics that Claude does not store even when you have sensitive topics in memory turned on. This includes sensitive identification numbers (SSN, government ID numbers, etc), criminal history, immigration status, or anything that violates our Acceptable Use Policy (AUP) in its memory. Claude will inform you when it's unable to update memory to include any of this information. Visit the Help Center to learn more.
> ZH: 为了保护您的安全和隐私，即使您打开了记忆中的敏感主题，Claude 也不会存储某些主题。这包括敏感的身份证号码（SSN、政府身份证号码等）、犯罪记录、移民身份或记忆中任何违反我们的可接受使用政策 (AUP) 的内容。当无法更新记忆以包含任何此类信息时，Claude会通知您。访问帮助中心了解更多信息。

## 入门 / Getting started

> EN: Memory is on by default on Free, Pro and Max plans across web, desktop, and mobile. Note that saving sensitive topics in memory is off by default. On iOS and Android, update to the latest version of the mobile app to get the most recent updates. For Team and Enterprise, admins control availability for their organization, and memory is off for individual users until they turn it on.
> ZH: 在 Web、桌面和移动设备上的 Free、Pro 和 Max 套餐中，记忆默认处于打开状态。请注意，默认情况下，将敏感主题保存在记忆中是关闭的。在 iOS 和 Android 上，更新到最新版本的移动应用程序以获得最新更新。对于团队和企业，管理员控制其组织的可用性，并且单个用户的记忆将处于关闭状态，直到他们将其打开。

> EN: Visit Settings > Memory to turn memory on and control what Claude remembers.
> ZH: 访问“设置”>“记忆”以打开记忆并控制Claude记住的内容。
