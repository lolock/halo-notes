## 新功能 / What's new

> EN: Claude Code and Claude Cowork. Agencies get new capabilities on the same cadence as our commercial users. Conversation history is stored locally on the agency-managed device. Inference runs inside a FedRAMP High authorized environment.
>
> ZH: Claude Code 和 Claude Cowork。各机构以与商业用户相同的节奏获得新功能。对话历史存储在机构管理的设备本地。推理在 FedRAMP High 授权环境中运行。

> EN: Billing that fits appropriations. Program offices can tie AI spend to appropriated funds with standard seats or they can define their own seat tiers with spend and model limits, and usage is purchased in fixed increments with a hard not-to-exceed cap. Administrators can track usage per user and per model in the admin console, and automatic burndown alerts warn them before the balance runs low.
>
> ZH: 适合拨款制度的计费方式。项目办公室可以通过标准席位将 AI 支出与拨款资金挂钩，也可以自行定义带有支出和模型限制的席位层级，使用量以固定增量购买并设有硬性的不超上限。管理员可以在管理控制台中按用户和按模型跟踪使用量，自动消耗提醒会在余额不足前发出警告。

> EN: Administration that matches how departments are organized. Department-level administrators can allocate seats and prepaid usage to sub-agencies while allowing each to manage its own users. Administrators can use SCIM group mappings to set rate limits, dollar caps, and allowed models for specific seat tiers. Additionally, layered configuration sets defaults for sub-agencies including what Claude can connect to, which features are available, and instructions that guide how Claude interacts with users.
>
> ZH: 与部门组织结构匹配的管理方式。部门级管理员可以将席位和预付费使用量分配给下属机构，同时允许每个机构自行管理其用户。管理员可以使用 SCIM 组映射来设置特定席位层级的速率限制、金额上限和允许使用的模型。此外，分层配置为下属机构设置默认值，包括 Claude 可以连接什么、哪些功能可用，以及指导 Claude 如何与用户交互的指令。

## 安全与监督 / Security and oversight

> EN: Oversight by design. Every administrative action is recorded in a hash-chained audit log that organization administrators can review directly in the product. Sensitive operations on Anthropic's side require two-person approval. Usage exports are metering data only so agencies can answer ATO and IG requests without moving sensitive material.
>
> ZH: 设计上内置监督。每个管理操作都记录在哈希链审计日志中，组织管理员可以直接在产品中查看。Anthropic 方执行的敏感操作需要双人审批。使用量导出仅为计量数据，使机构能够回应 ATO 和 IG（监察长）请求而无需移动敏感材料。

> EN: For security teams evaluating the desktop deployment, we're publishing our FedRAMP Secure Configuration Guide as a public-facing document that customers can use to configure their Claude for Government product in a secure manner.
>
> ZH: 对于评估桌面部署的安全团队，我们正在发布 FedRAMP 安全配置指南，作为公开文档，客户可以用其以安全方式配置他们的 Claude for Government 产品。

> EN: In addition, FedRAMP requires us to provide our formal change notification, which contains details associated with this change.
>
> ZH: 此外，FedRAMP 要求我们提供正式的变更通知，其中包含与此变更相关的详细信息。

> EN: Lastly, a penetration-test summary is available for the new desktop client, and subsequent follow up penetration-tests summaries will be provided once available. The change notification and pentest summary are available under NDA through Anthropic's trust center. The application deploys through standard agency MDM platforms.
>
> ZH: 最后，新桌面客户端的渗透测试摘要已经可用，后续的渗透测试摘要将在可用时提供。变更通知和渗透测试摘要可通过 Anthropic 的信任中心在 NDA（保密协议）下获取。应用程序通过标准机构 MDM 平台进行部署。
